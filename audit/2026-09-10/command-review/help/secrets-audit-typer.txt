Usage: -c secrets audit [OPTIONS] [arg]

  Audit sessions for leaked keys and passwords, masked; a rotation worklist.

  With no session arg the whole directory scope is scanned. Output is one row
  per distinct secret (kind, salted fingerprint, spread); the value itself is
  never printed, in --json mode included.

Arguments:
  arg  Session: @N, @A:@B, id prefix, or name

Options:
  --candidates             Include high-entropy review candidates (noisy)
  --since <str>            Sessions started on/after DATE (YYYY-MM-DD, ISO,
                           today, @N)
  --before <str>           Sessions started before DATE; --before today skips
                           today's
  --codex                  Read Codex sessions
  --claude                 Read Claude Code sessions (default)
  --path <path>            Inspect DIR instead of cwd
  --json                   Raw JSONL records, never truncated
  -n, --limit <int range>  Cap printed rows (0 = all)  [x>=0]
  --file <path>            Read this JSONL file directly; detect Claude or
                           Codex
  --recursive              Include sessions recorded in descendant directories
  --worktrees              Include registered Git worktrees of the selected
                           repository
  --claude-root <path>     Claude config root to search; repeat for multiple
                           profiles
  --include-agents         Include nested Claude agent transcripts
  --archives               Include Codex archived_sessions alongside active
                           sessions
  --coverage               Report searched/unavailable roots and discovered
                           sources on stderr
  --help                   Show this message and exit.
