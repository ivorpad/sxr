# sxr command review for the next session

[commands-before-after.csv](commands-before-after.csv) contains the current CLI and proposed changes. Start by filtering `kind` to `command` for the command review, then filter by command or `priority` for the detailed options and interactions. `P1` identifies the first proposed implementation batch, `P2` later consistency work, `P3` lower-priority aliases or documentation, and `Keep` behavior to retain. Priorities are recommendations, not approved implementation tasks.

The report has 408 rows: 21 command surfaces covering 18 command entries (including bare `sxr` and hidden `secrets audit`), 305 current parameter entries, and 82 action, interaction, environment, proposed-option and work-state rows. Aliases are listed alongside their option. The same command has separate parser rows when direct invocation and root-prefixed invocation take different paths. Proposed options are explicitly marked as unavailable today.

`before` describes the uncommitted source tree at the start of this review, after the earlier 17-finding remediation. `after` is a proposal for the next session. Examples containing new options are proposals too. The installed `/opt/homebrew/bin/sxr` was not updated or used as the authority for this review. [surface.json](surface.json) records the Git revision, source/test hashes, parser declarations and all 21 captured help invocations. [probes.json](probes.json) contains 39 bounded observations using synthetic transcripts and a private cache. The report combines parser enumeration, implementation review and those observations. It does not claim every possible flag combination was executed.
